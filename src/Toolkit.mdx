## Skills

A skill is a written procedure Claude follows for one kind of job. Call it by
name (`/figma-library-from-code`) or just describe the job. `figma-library-from-code` keeps the
library right; `storybook-figma-sync` builds screens from it.

<Skills />

## MCPs

An MCP is a plug that lets Claude look things up in a tool and work in it.

<Mcps />

## A five-minute demo

1. `npm run storybook`: the system, live.
2. Open **Sync status** in this sidebar: every component, code and Figma side by side.
3. Start a Claude session: its first line is the same check, unprompted.
4. Open `figma/manifest.json` and search for `"keys"`: the handles that let Claude place real library components in any file.
5. Ask Claude to put a prototype into Figma, or bring a Figma screen back: made of library instances, with a notes overview of what is real, what was built by hand and what is missing.
